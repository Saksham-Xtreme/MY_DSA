**Algorithm / Logic Walkthrough**:

### Revision Cheat Sheet
- **Pointers**: A pointer stores the memory address of another variable. Format: `int *ptr = &var;`.
- **Pass by Value vs. Reference**: Pass by value copies the variable (`void func(int x)`), while pass by reference passes the actual memory address (`void func(int &x)`).
- **Control Flow**: Use `switch` for multi-way branching and loops (`for`, `while`, `do-while`) for iteration.
